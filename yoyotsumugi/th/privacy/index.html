นโยบายความเป็นส่วนตัว

อัปเดต 2 พฤศจิกายน 2026 นโยบายนี้อธิบายการจัดการข้อมูลของ YOYOTSUMUGI ซึ่งให้บริการโดย ddkklab แอปกำลังเตรียมเปิดตัว

ข้อมูลเกมบนอุปกรณ์ของคุณ

ชาวบ้าน ทรัพยากร ประวัติ การวิจัย เวลาเกม บันทึกป้องกันรางวัลโฆษณาซ้ำ และการตั้งค่าเสียงเก็บอยู่บนอุปกรณ์ ไม่มีระบบบัญชีหรือระบบหลังบ้านที่ผู้พัฒนาดูแล และไม่ส่งความคืบหน้าเกมไปเซิร์ฟเวอร์ของเรา เราไม่บันทึกไมโครโฟนหรือขอตำแหน่ง GPS ที่แม่นยำ การสำรองข้อมูลของระบบปฏิบัติการเป็นไปตามการตั้งค่าอุปกรณ์

โฆษณาและบุคคลที่สาม

โฆษณารับรางวัลที่เลือกดูได้ใช้ Google AdMob (Google Mobile Ads SDK) จัดการความยินยอมผ่าน User Messaging Platform (UMP) ของ Google เราขอโฆษณาที่ไม่ปรับตามบุคคล ซึ่งไม่ได้หมายความว่าไม่มีการประมวลผลข้อมูล

SDK ของ Google อาจประมวลผลตำแหน่งโดยประมาณจากที่อยู่ IP ตัวระบุอุปกรณ์ การโต้ตอบกับผลิตภัณฑ์ ข้อมูลโฆษณา ข้อมูลแอปขัดข้อง ประสิทธิภาพ และการวินิจฉัยอื่น เพื่อแสดงและวัดผลโฆษณา วิเคราะห์ ป้องกันการฉ้อโกง และจัดการความยินยอม เราไม่ส่งข้อมูลบันทึกหมู่บ้านหรือสิทธิ์การซื้อไปยัง SDK โฆษณา

ทางเลือกการติดตามและโฆษณา

เมื่อเลือกใช้โฆษณาครั้งแรก อาจมีการขออนุญาต App Tracking Transparency (ATT) ของ Apple ตามความจำเป็น หากอนุญาต ตัวระบุอุปกรณ์อาจเชื่อมกับข้อมูลบริษัทอื่นเพื่อวัดผลโฆษณา ตัวระบุอุปกรณ์ถือเป็นข้อมูลที่ใช้ติดตาม ปฏิเสธแล้วเล่นเกมพื้นฐานต่อได้ ระบบจัดการโฆษณาเฉพาะเมื่อความยินยอมและเงื่อนไขการแสดงอนุญาต

ATT และความยินยอมโฆษณาตามภูมิภาคแยกกัน เปลี่ยนสิทธิ์ติดตามได้ในการตั้งค่า iOS เมื่อจำเป็นสามารถทบทวนความยินยอมตามภูมิภาคผ่านการตั้งค่าความเป็นส่วนตัวโฆษณาในแอป คุณเลือกไม่ดูโฆษณาได้

การซื้อผ่าน Apple StoreKit

ช่องวิจัยและก่อสร้างเพิ่มเติมเป็นการซื้อแบบไม่สิ้นเปลือง ส่วนแพ็กตั๋วลดเวลาเป็นการซื้อแบบสิ้นเปลือง ธุรกรรมและสิทธิ์ที่ยืนยัน รวมถึงบันทึกการให้ ใช้ และเพิกถอนตั๋ว เก็บใน Keychain ของอุปกรณ์เพื่อจัดการสิทธิ์ คืนช่องเพิ่มเติม รักษายอด และป้องกันการให้ซ้ำ การคืนค่าการซื้อไม่ให้ตั๋วสิ้นเปลืองซ้ำ และไม่รับประกันการโอนเมื่อติดตั้งใหม่หรือเปลี่ยนอุปกรณ์

เราไม่ได้รับหมายเลขบัตรหรือรหัสผ่านบัญชี Apple ไม่ส่งข้อมูลการซื้อไปเซิร์ฟเวอร์ของเราหรือ SDK โฆษณา การชำระเงินและบันทึกธุรกรรมที่ Apple ดูแลเป็นไปตามนโยบายของ Apple

การเก็บรักษาและลบ

ข้อมูลบันทึกอยู่ในอุปกรณ์ การลบแอป อุปกรณ์เสีย หรือเปลี่ยนอุปกรณ์อาจทำให้ความคืบหน้าหาย การคืนค่าการซื้อไม่คืนข้อมูลหมู่บ้าน ข้อมูลสำรองของระบบ รายการ Keychain และประวัติการซื้อ Apple อาจยังอยู่หลังลบแอป บุคคลที่สามเก็บและลบข้อมูลตามนโยบายของตน เราลบบันทึกทั้งหมดของพวกเขาไม่ได้

การประมวลผลระหว่างประเทศและเว็บไซต์นี้

Google, Apple และ GitHub ให้บริการทั่วโลก ข้อมูลที่ประมวลผลอาจถูกจัดการนอกประเทศของคุณตามนโยบาย รวมถึงมาตรการคุ้มครองการโอนและกระบวนการสิทธิความเป็นส่วนตัว ทางเลือกที่ใช้ได้ขึ้นกับที่อยู่ของคุณ ดูนโยบายจากลิงก์ด้านล่าง

เว็บไซต์นี้ให้บริการบน GitHub Pages เราไม่ได้เพิ่มสคริปต์วิเคราะห์หรือโฆษณา ข้อมูลการเข้าถึงโฮสติ้งอาจประมวลผลตามประกาศความเป็นส่วนตัวของ GitHub บริการที่เปิดจากโฆษณามีข้อกำหนดของตน

การเปลี่ยนนโยบาย

เราทบทวนนโยบายเมื่อคุณสมบัติหรือผู้ให้บริการเปลี่ยน และแสดงวันที่อัปเดตที่นี่ การเปลี่ยนแปลงสำคัญจะประกาศบนเว็บไซต์หรือในแอป พร้อมกระบวนการขอความยินยอมที่จำเป็น

เวอร์ชัน Android อยู่ระหว่างเตรียมการ

เวอร์ชัน Android กำลังทดสอบ ยังไม่เริ่มเผยแพร่หรือขายสินค้าบน Google Play ระบบใช้ Google Play Billing และเข้ารหัสข้อมูลการซื้อที่ยืนยันแล้ว ช่องเพิ่มเติม และประวัติการรับและใช้ตั๋วไว้ในอุปกรณ์ด้วยกุญแจ Android Keystore เราไม่ได้รับรหัสผ่านบัญชี Google หรือหมายเลขบัตร Android ไม่ใช้ Apple ATT แต่ใช้ Google UMP จัดการความยินยอมโฆษณาตามภูมิภาค ข้อมูลหมู่บ้านและบัญชีการซื้อบน Android ไม่รวมในการสำรองอัตโนมัติ และไม่รับประกันการย้ายข้อมูลหลังลบ ติดตั้งใหม่ หรือเปลี่ยนอุปกรณ์
