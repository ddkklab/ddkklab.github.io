隐私政策

更新日期：2026年11月2日。本政策说明 ddkklab 提供的 YOYOTSUMUGI 如何处理信息。应用正在准备发布。

设备上的游戏信息

居民、资源、历史、研究、游戏时间、广告奖励去重记录和声音设置均保存在您的设备上。没有开发者账号系统或开发者运营的后台服务，游戏进度不会发送到我们的服务器。我们不录制麦克风，也不请求精确 GPS 位置。操作系统备份遵循设备设置。

广告与第三方

可选的激励广告使用 Google AdMob（Google Mobile Ads SDK）。通过 Google 的 User Messaging Platform（UMP）管理同意。我们请求非个性化广告，但这并不代表不处理任何数据。

Google SDK 可能处理根据 IP 地址推算的大致位置、设备标识符、产品交互、广告数据、崩溃数据、性能数据及其他诊断信息，用于广告投放与衡量、分析、防欺诈和同意管理。我们不会向广告 SDK 发送村庄存档或购买权益。

跟踪与广告选择

首次选择使用广告时，可能根据需要请求 Apple 的 App Tracking Transparency（ATT）权限。若允许，设备标识符可能与其他公司的数据关联，用于广告衡量。设备标识符被视为用于跟踪的数据。即使拒绝，您仍可继续基础游戏。仅在同意和投放条件允许时处理广告。

ATT 与地区广告同意是不同机制。您可在 iOS 设置中更改跟踪权限。需要时，可通过应用内的广告隐私设置查看地区同意。您也可以选择不看广告。

Apple StoreKit 购买

额外研究和建造槽位属于非消耗型购买，加速券礼包属于消耗型购买。已验证的交易、权益及加速券发放、使用和撤销记录保存在设备钥匙串中，用于管理访问权限、恢复额外槽位、维护余额和防止重复发放。恢复购买不会再次发放消耗型加速券，也不保证重新安装或更换设备后能够转移。

我们不会收到银行卡号或 Apple 账户密码。购买数据不会发送到我们的服务器或广告 SDK。Apple 管理的付款和交易记录适用其政策。

保留与删除

存档保存在本地。删除应用、设备故障或更换设备可能导致进度丢失。恢复购买不会恢复村庄存档。删除应用后，操作系统备份、钥匙串条目和 Apple 购买记录可能仍然存在。第三方的信息保留和删除遵循各自政策，我们无法删除其全部记录。

联系信息

请通过 support.ddkklab@gmail.com 联系 ddkklab。您发送的邮箱地址、消息和附件用于答复咨询和调查问题。我们会按该用途所需保留这些信息，并删除不再需要的信息。如需申请保留或删除，请联系我们。请勿发送密码、银行卡号、完整收据或整个存档文件。

跨境处理与本网站

Google、Apple 和 GitHub 在全球运营。它们处理的信息可能根据各自政策在您所在国家以外处理，包括其跨境传输保障和隐私权程序。您可用的隐私选择取决于所在地。请参阅下方链接中的政策。

本网站托管于 GitHub Pages。我们没有添加分析或广告脚本。托管访问记录可能根据 GitHub 隐私声明处理。通过广告打开的服务有各自的条款。

政策变更

功能或服务商发生变化时，我们会审查本政策并在此公布更新日期。重大变更将在网站或应用内公告，并履行所需的同意程序。
